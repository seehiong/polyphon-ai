    🎙️ Microphone Access & Security Guide

    Browser Security Restriction: Web browsers disable microphone access on unencrypted HTTP over local network IPs.

    🎙️+💻 How to Capture Meeting Tab Audio

    1. When the browser prompt appears, select the Chrome Tab or Window where your meeting is running (Google Meet, Zoom web, Microsoft Teams, Webex).
    2. Look at the bottom left of the selection window and make sure "Also share tab audio" (or "Share system audio") is CHECKED.
    3. Click Share. Polyphon will capture both your local microphone and remote meeting audio, silently mixing them without speaker feedback.
    4. When the meeting is over, click Stop & Finalize in Polyphon or click Stop Sharing on the Chrome banner.
